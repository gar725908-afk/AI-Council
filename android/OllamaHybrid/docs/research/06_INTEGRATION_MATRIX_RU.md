# Исследование 6 — матрица интеграции

Что брать готовым, что адаптировать, что писать самим. «Брать» означает
подключать библиотеку или переносить **идею** (архитектурное решение); код
сторонних приложений целиком не копируется. Лицензионные условия — в
[аудите](08_RISK_LICENSE_AUDIT_RU.md).

## Решения по компонентам

| Компонент | Решение | Источник | Почему |
|---|---|---|---|
| Инференс GGUF | **Брать** (уже): llama.cpp как библиотека | ggml-org/llama.cpp, MIT | Шире всех по моделям; CPU-варианты; свой JNI уже есть |
| Инференс Gemma 4 | **Брать** (уже): LiteRT-LM AAR | google-ai-edge/LiteRT-LM, Apache-2.0 | Официальные сборки Google, GPU |
| GPU для GGUF | **Адаптировать**: OpenCL-бэкенд llama.cpp + профили с откатом | llama.cpp `docs/backend/OPENCL.md`; идея профилей — AiPaca (GPL-3.0, только идея) | Adreno 7xx/8xx, без NPU-тулчейна |
| Офлайн STT | **Брать**: whisper.cpp | ggml-org/whisper.cpp, MIT | Тот же ggml |
| Офлайн TTS по-русски | **Брать**: Piper ru_RU через sherpa-onnx | k2-fsa/sherpa-onnx, Apache-2.0; голоса rhasspy/piper-voices | Русские голоса; Kokoro без русского |
| Эмбеддинги и RAG | **Писать** поверх llama.cpp (embedding-режим) + модели Qwen3-Embedding / EmbeddingGemma | Идея — Local AI, Nyral | Архив NEXUS уже хранит текст и цитаты |
| Каталог и загрузка моделей | **Своё** (уже) + идеи AiPaca: многопоточная докачка, Wi-Fi-режим | AiPaca (идея) | В NEXUS уже SHA-256, Range, найденные файлы |
| Агентный цикл на экране | **Писать** с идеями DroidClaw (детекторы залипания/повторов/дрейфа, скриншот при пустом дереве) | DroidClaw — без файла лицензии: только идеи | Устойчивость агента |

| Браузерный агент | **Писать** на WebView NEXUS: чтение DOM, клики, ввод, капча — владельцу | Идея — Operit (LGPL-3.0), Nyral (MIT) | Браузер NEXUS уже есть |
| MCP-сервер телефона | **Писать** поверх Mesh/LINK | Идея — Zafiro (MIT), Phone-MCP (MIT) | Закрытый канал уже есть |
| Linux-среда (PRoot) | **Отложить** | Operit (LGPL), Local AI (AGPL), OpenMinis (GPL) | Сотни МБ rootfs, отдельная модель угроз; польза не доказана |
| Локальный OpenAI-API | **Писать** (небольшой HTTP-сервер на телефоне) | Идея — AiPaca, ServLlama | Модель телефона для других приложений и ПК |
| MNN | **Не брать сейчас** | alibaba/MNN, Apache-2.0 | Третий формат без конкретной модели, ради которой он нужен |
