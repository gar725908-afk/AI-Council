# NEXUS Extension API v1

**Статус:** первая безопасная версия формата расширений  
**Пакет:** `.nex` (ZIP)  
**API:** `apiVersion: 1`

## 1. Что такое расширение v1

Расширение NEXUS v1 — декларативный пакет, а не загружаемая программа. Оно описывает метаданные, список действий и необходимые разрешения. Выполняет действия только встроенный в NEXUS runtime.

Это позволяет подключать сторонние наборы команд, не предоставляя пакету доступ к Android API, файловой системе, сети или внутренним данным приложения.

## 2. Структура пакета

```text
my-extension.nex
├── manifest.json
└── README.md        (необязательно)
```

Архив должен содержать файлы в корне. Вложенные каталоги, дублирующийся манифест, DEX, APK, JAR, SO, JS, Python, shell и любые дополнительные файлы запрещены.

Ограничения v1:
- ZIP: максимум 256 КиБ распакованного содержимого и 8 записей;
- manifest.json: максимум 64 КиБ;
- до 20 действий в одном расширении;
- до 80 символов в ID/названиях и до 4 КиБ в payload действия.

## 3. Пример manifest.json

```json
{
  "id": "example.quick-links",
  "name": "Quick links",
  "version": "1.0.0",
  "description": "Открывает официальные сайты по команде пользователя.",
  "apiVersion": 1,
  "capabilities": [
    "open_url",
    "clipboard_write",
    "show_message"
  ],
  "actions": [
    {
      "id": "open-notion",
      "title": "Открыть Notion",
      "type": "open_url",
      "payload": "https://www.notion.so"
    },
    {
      "id": "copy-template",
      "title": "Скопировать шаблон",
      "type": "copy_text",
      "payload": "Моя задача: ...\nКонтекст: ...\nОжидаемый результат: ..."
    },
    {
      "id": "show-ready",
      "title": "Показать сообщение",
      "type": "show_message",
      "payload": "NEXUS готов к работе"
    }
  ]
}
```

## 4. Доступные действия и разрешения

| Действие | Требуемое разрешение | Поведение |
|---|---|---|
| `open_url` | `open_url` | Открывает только HTTPS URL во внешнем приложении |
| `copy_text` | `clipboard_write` | Копирует заданную строку в системный буфер |
| `show_message` | `show_message` | Показывает короткое Android Toast-сообщение |

Все разрешения отключены по умолчанию. Пользователь выдаёт и отзывает каждое разрешение отдельно. Кнопка действия недоступна, пока соответствующее разрешение не выдано.

## 5. Установка и удаление

1. Создайте ZIP с корневым `manifest.json` и при необходимости `README.md`.
2. Переименуйте ZIP в `.nex`.
3. В NEXUS откройте Центр → Расширения → Установить пакет.
4. Проверьте имя, версию, список разрешений и описания действий.
5. Выдавайте только те разрешения, которые действительно необходимы.
6. При удалении NEXUS отзывает все разрешения этого расширения.

## 6. Ограничения безопасности

- Пакет не запускает код и не может регистрировать собственные классы.
- Модель или текст внутри расширения не могут самостоятельно выдать себе разрешения.
- Runtime повторно проверяет, что действие находится в сохранённом манифесте и что пользователь выдал требуемое разрешение.
- URL открывается только при схеме HTTPS, без user-info и нестандартного порта.
- Расширение не получает API-ключи провайдеров, cookie, историю чатов, локальные файлы, Root, Accessibility или Shizuku.
- Импорт пакета не означает, что его издатель проверен или что его содержимое доверенное.

## 7. Что намеренно не входит в v1

Плагины произвольного Kotlin/Java, DEX, JNI/native, JavaScript/WASM, сетевые вебхуки, автоматизация браузера и доступ к личным данным требуют отдельного sandbox, разрешений, подписи издателя и аудита. Они не должны добавляться обходным путём через манифест v1.
