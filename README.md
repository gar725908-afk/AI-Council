# AI Консилиум (AI Council)

Desktop-приложение на Python / PySide6 / Qt WebEngine для одновременной работы нескольких веб-ИИ с общим чатом и отдельными профилями.

## Возможности
- ChatGPT, Claude, DeepSeek, Kimi, Grok, Qwen, Алиса.
- Общий совет ИИ, рабочие пространства.
- Добавление участников по HTTPS-адресу через настройки.
- Сохранение авторизации локально в отдельных профилях.
- Для нового сайта может потребоваться адаптер веб-интерфейса.

## Windows: быстрый запуск

1. Скачайте архив из **Releases** и распакуйте его в любую папку, например `D:\AI-Council`.
2. Один раз запустите `INSTALL_AND_LAUNCH.bat`. Скрипт создаст локальное окружение `.venv`, установит зависимости и запустит программу.
3. В следующие разы запускайте `START_AI_COUNCIL.bat` или `OPEN_AI_COUNCIL.ps1`.
4. Учетные записи сервисов добавляются пользователем отдельно на его компьютере.

Также можно запускать напрямую:
```
python -m pip install -r requirements.txt
python main.py
```

## Конфиденциальность

Публичная версия содержит только исходный код и технические файлы.
Аккаунты, пароли, cookies, данные профилей, личные переписки, `.env`, документы и журналы не публикуются.
